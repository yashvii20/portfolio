## 💻 How to View Locally

1. **Directly in Browser:**
   Double-click `d:\portfolio\index.html` to open it in Chrome, Edge, Firefox, or Safari.

2. **Using Local Server:**
   ```bash
   # Using npx serve
   npx serve d:\portfolio

   # Or using Python (if installed)
   cd d:\portfolio && python -m http.server 3000
   ```

## 🌐 Easy Deployment Options

- **GitHub Pages:** Push this repository to GitHub and enable Pages in `Settings -> Pages`.
- **Vercel:** Run `vercel` inside `d:\portfolio` or import the GitHub repository.
- **Netlify:** Drag and drop the `portfolio` folder directly into Netlify Drop.
